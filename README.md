## 🔬 Understanding the Metrics

| Metric | What it Measures | Range |
|--------|------------------|:-----:|
| **BERT Score** | Semantic similarity using contextual embeddings | -1 to 1 |
| **BLEU-1/2/4** | N-gram precision (unigram, bigram, 4-gram) | 0 to 1 |
| **ROUGE-L** | Longest common subsequence overlap | 0 to 1 |
| **Exact Match** | Identical response after normalization | % |
| **Partial Match** | Word overlap percentage with reference | % |
| **Inference Latency** | Time to generate response | ms |
| **Memory Footprint** | GPU memory consumption | GB |
